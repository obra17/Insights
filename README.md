# obrainsights.com

Static marketing site for Obrainsights. Plain HTML + CSS + a tiny JS file, generated by a dependency-free Python script.
Source of truth for copy and prices: `../Obrainsights_Business_Plan.md`.

## Layout
- `tools/build.py` – all page content, prices, FAQs, JSON-LD, sitemap, robots.txt, llms.txt. Edit here, then rebuild.
- `tools/check_links.py` – crawls a local server and fails on broken internal links or invalid JSON-LD.
- `public/` – the built site (committed, so hosts can deploy it with no build step).

## Build & check locally
```bash
python3 tools/build.py
cd public && python3 -m http.server 8787 &
python3 tools/check_links.py http://localhost:8787
```

## Deploy (no build step needed; publish directory = `public`)
- **Cloudflare Pages**: push repo to GitHub → Pages → Create project → connect repo → build command: *(none)* (or `python3 tools/build.py`), output dir: `public`. Then Custom domains → `obrainsights.com` + `www`.
- **Netlify**: New site from Git → publish directory `public`. Or `npx netlify deploy --prod --dir=public`.
- **Vercel**: Import repo → Framework "Other" → output directory `public`.

## DNS (domain is at Porkbun)
Either change nameservers to Cloudflare (if using Pages) or, at Porkbun, add the records the host gives you
(apex ALIAS/A + `www` CNAME). Then verify `https://obrainsights.com/sitemap.xml` and submit it in Google Search Console / Bing Webmaster Tools.
