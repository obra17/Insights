FAQ

What agents do you set up?

The starting catalog is Inbox Triage, Content Repurposing, and Lead Research. Each agent is built for one job.

Whose accounts does the agent run on?

Yours. Agents run on accounts you own, and you pay model and API usage directly.

Can an agent send messages or spend money for me?

Only with a human-approval step that you control.

What does the retainer cover?

Monitoring, fixes when models or APIs change, prompt and eval tuning, and a set number of improvements each month, depending on tier. Retainers are month-to-month.
